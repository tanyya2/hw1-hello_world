# OutNYC

Plan your time out in New York City. Pick where you are, and OutNYC finds real places nearby and uses AI to turn them into a plan that fits your time, budget and vibe.

## What you can do

- **Find places** near you: coffee, restaurants, bars, clubs, museums, parks, bookstores and dessert, as a list or on a map.
- **Make a plan** for a few hours out, built from real nearby places.
- **Rate plans** with 👍 / 👎 and browse everyone's plans.

## Built with

Next.js, Supabase, Google Maps Platform (Places and Maps), Google Gemini and OpenStreetMap (neighborhood names), deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Needs a `.env.local` with Supabase, Gemini and Google Maps keys and a Google Map ID.
